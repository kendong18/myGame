게임 방법

  • 이동 : WASD 또는 방향키 (모바일: 화면 드래그)
  • 공격 : 무기가 자동으로 공격합니다. 피하는 것에 집중하세요!
  • 경험치 : 적이 떨어뜨린 보석을 모아 레벨업하세요.
  • 레벨업 : 새 무기, 무기 강화, 패시브 아이템 중 하나를 고릅니다. (숫자키 1~4)
  • 진화 : 무기를 최대 레벨(8)로 만들고 짝이 되는 패시브를 가진 상태로 보물상자를 열면 무기가 진화합니다.
  • 보물상자 : 엘리트 몬스터와 보스가 떨어뜨립니다.
  • 화로 : 맵의 화로를 부수면 치킨, 자석, 골드 등이 나옵니다.
  • 목표 : 10분을 버티면 마왕이 등장합니다. 마왕을 쓰러뜨리면 승리!
  • 일시정지 : ESC 또는 P
