# 게임 코드 버그 점검 보고서

2026-09-30 점검

## 요약

자동 테스트는 모두 통과했지만, 코드 리뷰에서 버그 후보 8개를 찾았다. 그중 게임 플레이나 진행 저장에 직접 영향을 주는 것은 5개다.

- 점검 대상: `scripts/` 폴더 전체(약 8,100줄)와 아직 커밋하지 않은 아이콘 UI 변경
- 점검 방법: Godot 헤드리스 자동 테스트 실행 + 코드를 한 줄씩 읽는 리뷰
- 한계: 버그는 코드를 읽고 찾은 것이며, 게임을 직접 실행해 재현해 보지는 않았다.

## 발견한 버그

가장 먼저 고칠 것은 1번(대시 키 오선택)과 2번(세이브 초기화)이다. 플레이어가 실제로 겪을 가능성이 가장 높거나, 피해가 가장 크다. 고친 버그는 상태 칸을 바꿔 둔다.

| # | 심각도 | 위치 | 증상 | 상태 |
| --- | --- | --- | --- | --- |
| 1 | 높음 | `scripts/hud.gd:480` | 대시 키(Space, 패드 A)를 누르면 레벨업 1번 선택지가 골라짐 | 수정 완료 |
| 2 | 높음 | `scripts/save_data.gd:107` | 저장 중에 게임이 꺼지면 세이브가 깨지고 진행 상황이 초기화됨 | 수정 완료 |
| 3 | 중간 | `scripts/main.gd:1424` | 레벨업과 보급 상자가 같은 프레임에 열려 창이 겹침 | 수정 완료 |

| 7 | 낮음 | `scripts/main.gd:173` | 일시정지 중 F11을 누르면 전체 화면 체크박스가 실제와 어긋남 | 수정 완료 |

### 1. 대시 키로 레벨업 선택지가 골라짐

- 상황: 적 무리 사이에서 Space를 연타하다가 레벨업 창이 뜬다. 창은 1번 버튼에 포커스를 주고, Space는 버튼을 누르는 키(`ui_accept`)이기도 해서 선택지를 읽기 전에 1번이 적용된다.
- 패드 A도 같은 문제가 있고, 보급 상자 창(`hud.gd:508`)도 같은 방식으로 바로 닫힌다.
- 고치는 방향(둘 중 하나 결정 필요): 창이 뜨고 약 0.3초 동안 선택 입력을 무시하거나, 창이 뜰 때 눌려 있던 키를 뗄 때까지 기다린다.

### 2. 세이브 파일이 깨지면 진행 상황이 사라짐

- 상황: `save()`는 `save.json`을 비우고 그 자리에 다시 쓴다. 그 사이에 게임이 꺼지면 파일이 반만 쓰여 깨진다.
- 다음 실행 때 `load_data()`는 읽기에 실패하면 조용히 기본값(골드 0, 강화 없음)으로 시작한다. 이어지는 첫 저장이 깨진 파일을 덮어써서 복구할 수 없다.
- 고치는 방향: 임시 파일에 쓴 뒤 이름을 바꾸고, 이전 파일을 `save.bak`으로 남겨 둔다. 읽기에 실패하면 백업에서 불러온다.

### 3. 레벨업과 보급 상자 창이 겹침

- 상황: 레벨업에 필요한 마지막 보석을 주우면서 동시에 상자 위에 선다. 보석 처리(`_update_gems`)에서 레벨업 창이 열리고, 같은 프레임의 아이템 처리(`_update_pickups`)에서 상자 창이 그 위에 또 열린다.
- 상자를 닫으면 레벨업 선택지가 새로 뽑혀, 처음에 본 선택지가 바뀐다. 효과음도 한 번 더 난다.
- 고치는 방향: `_update_pickups()`에서 상태가 플레이 중이 아니면 상자를 열지 않는다.

### 4. 정지된 원거리 적이 탄을 쏨

- 상황: 원거리 적이 540px보다 멀리서 다가오는 동안 발사 타이머(`shoot_t`)가 0 아래로 내려간다. 거리 안으로 들어와 냉각+전기 정지 반응에 걸려도 곧바로 탄을 쏜다.
- 고치는 방향: 발사 조건에 `e.stun <= 0.0`을 추가한다.

### 5. 폭탄 열매가 겹쳐서 소환됨

- 상황: 분노 상태의 온실 나무는 열매 4개를 소환하지만, 간격을 3으로 나눠 계산한다. 그래서 1번째와 4번째가 같은 자리에 나온다.
- 두 열매는 하나처럼 보이다가 함께 터져, 피해가 두 배가 된다.
- 고치는 방향: 소환하는 개수(4 또는 3)로 나눈다.

### 6~8. 사소한 문제

- 6번: 보석이 250개일 때 새 경험치는 기존 보석에 합쳐진다. 이때 방금 주운(`dead`) 보석에 합쳐지면 그 경험치는 사라진다. 합칠 보석을 고를 때 주운 보석은 빼면 된다.
- 7번: F11은 설정값만 바꾸고 일시정지 화면의 체크박스는 그대로 둔다. 그래서 전체 화면을 풀려면 체크박스를 두 번 눌러야 한다. F11을 누를 때 체크박스도 갱신하면 된다.
- 8번: 슬라이더를 0에서 1까지 끌면 파일을 약 20번 쓰고 클릭음도 그만큼 난다. 끌기를 끝낼 때(`drag_ended`) 한 번만 저장하면 된다.

## 아이콘 UI 변경 점검

아직 커밋하지 않은 아이콘 UI 변경에서는 뚜렷한 버그를 찾지 못했다.

- 점검한 파일: `hud.gd`, `main.gd`, `translations.gd`, `item_slot.gd`, `item_icons.gd`
- 바뀐 내용: 화면 아래의 글자 목록이 무기/아이템 아이콘 칸으로 바뀐다. 일시정지 화면에서는 아이콘을 선택하면 설명이 나오고, 레벨업과 보급 상자 창에도 아이콘이 붙는다.
- 확인한 것: 새로 넣은 문구 5개의 영어 번역, 회복 선택지의 아이콘, 진화한 무기 표시, 일시정지 중 아이콘 애니메이션
